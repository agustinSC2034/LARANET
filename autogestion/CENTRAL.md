# Central y soporte

SDK oficial https://web.central.chat/widget/core.js. brand.centralChannelKey vacío; no se carga SDK ni se monta widget si falta la clave. No se encontró una clave LARANET confirmada en los repositorios inspeccionados.

Una vez configurado: instancia oculta, espera central-chat-mount, show()/maximize(), cierre hide(), prefill() solo con temas genéricos. Nunca autoenvía ni incluye documento, IDA, teléfono, mail, dirección, contraseña o token. Sin shadow DOM, observers ni click simulation.

Mientras falta la clave, el botón abre un diálogo con WhatsApp oficial verificado en la web LARANET. El usuario decide abrir/enviar. No se modificó Botmaker live.
